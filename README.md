# ⏱️ TimeItOut

App iOS nativa (SwiftUI) para controlar pagos recurrentes, con cuenta atrás, widgets y cálculo del ahorro mensual.

## ✨ Funcionalidades

- Pagos **mensuales, trimestrales o anuales**, con opción de repetición
- **Cuenta atrás** y un icono con **anillo de progreso** por cada pago
- **Widget** que muestra cuánto falta para cada pago
- Cálculo, a partir del sueldo mensual, de **cuánto se lleva cada mes en pagos y cuánto queda**
- App y widget comparten datos y ordenan los pagos por cercanía de fecha
